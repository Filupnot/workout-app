# Logging a workout

## The rhythm

1. Finish a set and tap **Start rest**. The timer starts immediately and a workout begins if none is open.
2. While you rest, pick the exercise; the first time in a session, the picker opens for you. Recent exercises appear first. Type a new name to add it on the spot.
3. Enter the weight and reps you actually did and tap **Log set**. Logging never changes the timer.
4. The next set is prefilled with your last values. On the first set of an exercise, values come from last time, and **Last time** shows how many days ago that was, the date, and every set.

Three rows are shown as a guide. Dashed rows are suggestions only and never count as sets. Log a fourth set whenever you like.

- **Fix a set:** tap its weight or reps, change the values, and tap **Save correction**. Tap **×** to remove a set.
- **Units:** tap `lb`/`kg` in the entry row to switch for that set. The default unit is in Settings.
- **Angle and notes:** open **Angle and notes** under the sets. If sets already exist, a new angle starts a separate entry for the same exercise, so each variant keeps its own sets and history.
- **Rowing:** tap **+ Rowing** and enter any two of time (`m:ss`), distance (meters), and average split (`m:ss` per 500 m). The third is calculated. If all three disagree by more than a second of split, the app asks you to fix them.
- **Stretch and notes:** check **Stretched** and add a session note, then tap **Finish workout**. Finishing also stops the rest timer.

Unsaved entries are kept across reloads, and an unfinished workout reopens where you left it.

## Rest timer

- **Restart** replaces the current countdown. **Skip** clears it. **−15** and **+15** adjust the countdown you are in. The default duration (90 seconds) is in Settings.
- The timer counts from a saved end time, so it stays correct after switching tabs, reloading, or locking the phone. After zero it counts up as negative overtime (for example `-0:25`).
- It stays pinned at the top while you scroll or type.

## Sound

The **Soft sound when rest ends** setting is off by default. When it is on, one short tone plays at zero, but only while Workout is open and on screen. The app never asks for notification permission and does not alert you in the background. If the phone is locked or the app is hidden when rest ends, you see the overtime when you come back and no delayed tone plays. The iPhone ring/silent switch may mute the tone. Use **Play test sound** in Settings to check.

## Installing on iPhone

In Safari, tap Share, then **Add to Home Screen**. The installed app opens full screen and works offline after the first load. Everything also works in Safari without installing.
